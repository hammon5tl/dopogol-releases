# DopoGol Betting Bot

Repository pubblico dedicato esclusivamente alle release ufficiali di DopoGol Betting Bot.

Il codice sorgente non è pubblicato qui. Scarica Windows o macOS dalla sezione **Releases**. Le build includono un manifest SHA-256 usato dal controllo aggiornamenti integrato nell'app.

> Le build macOS devono essere firmate e notarizzate prima della distribuzione production.
