# DopoGol Betting Bot

DopoGol Betting Bot permette di collegare e gestire i propri account Betsson da un'unica applicazione, automatizzando l'accesso e le operazioni del bot.

## Come iniziare

1. Scarica la versione più recente per Windows o macOS dalla sezione [Releases](https://github.com/hammon5tl/dopogol-releases/releases/latest).
2. Avvia l'app e inserisci la chiave di accesso.
3. Aggiungi i tuoi account Betsson ed effettua il login.

Per richiedere una chiave di accesso o ricevere assistenza, scrivi a [DopoGol Support](https://t.me/DopoGol_Support).
